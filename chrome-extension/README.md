# Extension Chrome - Vinted Manager Synchronizer

Cette extension Chrome officielle permet d'extraire automatiquement les métriques de vos comptes Vinted (**vues, favoris/likes, messages, ventes**) et de les synchroniser directement avec votre application **Vinted Manager**.

---

## 🛠️ Instructions d'Installation dans Google Chrome

1. Ouvrez **Google Chrome**.
2. Dans la barre d'adresse, tapez :
   ```
   chrome://extensions
   ```
3. En haut à droite de la page, **activez le Mode développeur** (interrupteur bleu).
4. En haut à gauche, cliquez sur le bouton **Charger l'extension non empaquetée**.
5. Sélectionnez le dossier :
   ```
   /Users/florencio/Documents/Vinted Manager/chrome-extension
   ```
6. L'extension **Vinted Manager - Extension de Synchronisation** s'affiche instantanément dans vos extensions Chrome ! 🎉

---

## 🚀 Comment l'utiliser :

1. Connectez-vous à votre compte **Vinted** sur [vinted.fr](https://www.vinted.fr).
2. Cliquez sur l'icône de l'extension **Vinted Manager** dans la barre d'outils Chrome.
3. Vérifiez l'URL du serveur (par défaut `https://vintedmanager-bkgg.vercel.app`).
4. Cliquez sur **⚡ Scraper & Synchroniser**.
5. Les métriques (vues, likes, messages, ventes) sont instantanément envoyées à Vinted Manager et les scores du calendrier sont recalculés !
